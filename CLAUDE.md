## Merkidentiteit — Belangrijkste regel

**Bamboo is NIET activistisch.** Dit is geen The Good Roll of Who Gives A Crap. Het merk positioneert zich als de **slimme, volwassen keuze** die comfort, duurzaamheid en gebruikswaarde combineert. Kopers moeten zich **slim voelen, niet bestraft**.

### Tone of voice
- Jong, direct, anti-verspilling — niet zwaar activistisch
- Premium in gevoel, niet elitair in toon of prijsframe
- Zakelijk genoeg voor B2B, menselijk genoeg voor social en webshop
- Duurzaam zonder schuldprediking

### Altijd
- Spreek in "je/jij", nooit "u"
- Lead met **gebruikswaarde** (meer vellen, langer doen, minder vaak kopen)
- Daarna productgevoel (zacht, sterk, premium of puur)
- Pas daarna duurzaamheid (boomvrij, plasticvrij, FSC, biologisch afbreekbaar)
- Gezondheidsclaims (hypoallergeen) als ondersteuner
- **Minimaal 2 van deze 3 in elke uiting**: meer gebruikswaarde, minder verspilling, geen bomen

### Nooit
- Moreel prediken of eco-schuldgevoel creëren
- "Red de planeet" taal of fake motivational quotes
- Engels gebruiken (tenzij Nathan expliciet vraagt)
- Stijf/corporate taalgebruik
- Duurzaamheid noemen zonder praktisch voordeel (converteert zwak)
- Prijs per doos vergelijken — altijd **waarde per gebruik**

## Productarchitectuur

Er zijn strategisch **3 kernlijnen** en **3 volumeformaten**. Alle 9 Bol listings zijn variaties hierop.

### 3 Kernlijnen
| Lijn | Positionering | Koper |
|------|---------------|-------|
| **Ongebleekt 2 laags** (300 vel) | Slim & rationeel — de nuchtere basiskeuze | Prijsbewuste huishoudens |
| **Ongebleekt 3 laags** (250 vel) | **HERO PRODUCT** — premium natuurlijk comfort | Bewuste huishoudens die comfort willen |
| **Blanc 3 laags** (250 vel) | Brugproduct — vertrouwd wit, makkelijke overstap | Comfortgerichte overstappers |

### 3 Volumes
- **24 rollen** — proef/instap (funnel entry)
- **48 rollen** — standaard hoofdvolume
- **96 rollen** — bulk, retentie, B2B, subscription

### Hero: Ongebleekt 3 laags 48 rollen
Dit is het sterkste product. Waarde + comfort + duurzaamheid komen hier samen. Moet in alle content en ads **hero positie** krijgen.

---

## USP Hierarchie (in deze volgorde communiceren)

1. **Meer vellen per rol** — 300 vel (2 laags) / 250 vel (3 laags). 48 rollen = ~100 normale rollen, 96 = ~200.
2. **Langer doen, minder vaak kopen** — voorraadrust, minder bestelmomenten
3. **Comfort** — 3 laags = zacht én sterk. 2 laags = slim en functioneel.
4. **Boomvrij** — 100% FSC bamboe i.p.v. hout
5. **Plasticvrij verpakt** + biologisch afbreekbaar
6. **Hypoallergeen** — vooral ongebleekte lijnen, gevoelige huid

## Routine Testing Rules

When testing routines for this client, follow these rules:

### Skip during testing
- **All Meta Ads routines** — these interact with live ad accounts and can pause/scale/create real campaigns. Never test these without Leon's explicit approval.
  - `ad-performance-loop.md` (auto-pauses and scales ads)
  - `bulk-ads-uploader.md` (creates real campaigns)
  - `create-meta-campaign.md` (creates real campaigns)
  - `m17-pixel-warmup.md` (touches live pixel)
  - `m19-meta-performance.md` (read-only but depends on Meta API credentials)
  - Any routine with `meta` or `ads` in the filename

### Safe to test
- Routines that only READ data (Shopify sync, Google Ads sync, competitor scraping)
- Routines that write to Airtable or send Telegram notifications
- Routines that process email or generate reports

### Testing workflow
1. Source the `.env.routines` file first
2. Run the routine as a prompt in Claude Code
3. Verify output in Airtable and Telegram
4. If it works → mark as tested in the routine registry
5. If it fails → document the error, do NOT retry blindly

### Credentials
- Never hardcode API keys in routine files
- All credentials come from `.env.routines`
- If a credential is missing, ask Leon — do not guess or use placeholder values
