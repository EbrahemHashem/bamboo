# Content Templates — Bamboo

Herbruikbare templates voor de Content Machine. Elk template is een prompt-pattern dat het systeem gebruikt bij specifieke content types.

---

## Template 1: Hero Static Ad (Ongebleekt 3 laags 48 rollen)

**Doel:** Conversie-ad voor het belangrijkste product van het merk.

**Visual prompt pattern:**
```
Volwassen, nuchtere productshot van Bamboo ongebleekt 3 laags 48 rollen doos, rustige badkamer setting, warm natuurlijk licht, focus op product, subtle bamboe accenten in achtergrond. Niet luxury-zweverig, wel premium. Kleuren: warm beige, off-white, near black tekst. Geen felgroene eco-clichés. Tekstruimte linksboven voor hook overlay.
```

**Copy pattern:**
```
[HOOK uit waarde-categorie]

48 rollen = ~100 normale rollen.
[PRODUCT REGEL — ongebleekt 3L detail]
[DUURZAAMHEID REGEL — boomvrij/plasticvrij]

[CTA]
```

**Voorbeeld:**
> Waarom nog kleine rollen die snel op zijn?
> 
> 48 rollen ongebleekt 3 laags bamboe = gemiddeld 100 normale rollen. 250 vel per rol, zacht en sterk in dagelijks gebruik. Volledig boomvrij, plasticvrij verpakt.
> 
> Meer weten → link in bio

## Template 2: Comfort Carousel (5 slides)

**Doel:** Comfort-zoekende mainstream doelgroep (vooral Blanc 3 laags 48).

**Slide structuur:**
1. **Hook slide**: "Duurzaam hoeft niet ruw te zijn"
2. **Probleem**: kleine rol, ruw papier, snel op
3. **Oplossing**: Bamboo 3 laags wit — 250 vel, zacht, sterk
4. **Bewijs**: 48 rollen vergelijking
5. **CTA**: "Kijk 'm hier"

**Visual style:** warme badkamer stills, hand-held productshots, subtiele vergelijking-beelden

## Template 4: Contrast Static (Bamboo vs supermarkt)

**Doel:** Rationele waarde-bewustmaking, cold traffic.

**Visual prompt:**
```
Split-screen contrast: links gewone kleine supermarkt toiletpapier rol, rechts Bamboo 3 laags rol, tekst overlay met aantal vellen (gewoon ~180 vel, Bamboo 250-300 vel). Schone productshot stijl, niet aggressief polemisch. Focus op het rekensommetje, niet op "slechte" supermarkt.
```

**Copy pattern:**
```
Gewone rol: ~180 vel. Bamboo rol: 300 vel.

Kleine rekensom: 48 Bamboo rollen doen net zo lang als ~100 standaard rollen.
Langer doen, minder vaak kopen, volledig boomvrij.

Slimmer, niet schreeuweriger.
```

## Template 6: B2B Outreach Email (voor handmatig gebruik)

**Doel:** Nathan gebruikt deze bij eigen B2B outreach (niet automatisch verzonden).

```
Onderwerp: [Voornaam], iets beters dan commodity toiletpapier voor [Locatie type]

Hoi [voornaam],

Wij leveren een bamboe toiletpapierlijn die langer meegaat per rol en representatief blijft op locatie — interessant voor kantoren, boutique hotels en praktijken die iets beters willen dan commodity rollen.

Wat je concreet krijgt:
• 48 of 96 rollen per doos — minder bestelmomenten
• 3 laags premium comfort — prettig voor gasten/medewerkers
• Volledig boomvrij (FSC bamboe) — past in je duurzaamheidsverhaal
• NL leverancier, snelle logistiek

Zin om een proefdoos te proberen? Ik stuur er graag eentje op.

[naam]
Bamboo Disposables BV
```
